# Superstore Sales Insights with Power BI

🚀 **Project Title**: Superstore Sales Insights with Power BI  
📊 **Tools Used**: Power BI | DAX | Excel | Data Visualization

## 🔍 Project Overview
In this project, I analyzed the **Superstore dataset** to uncover hidden business insights using Power BI. I cleaned and transformed the data, applied powerful **DAX functions**, and built an interactive **dashboard** to provide a clear view of business performance across categories, regions, and customer segments.

## 💡 Key Features
- Dynamic **Sales & Profit Analysis**
- Regional **Performance Breakdown**
- **Top & Bottom Performing** Products
- **Customer Segment Trends**
- **Shipping Mode Impact** on Profitability

## 📈 Power BI Dashboard Highlights
- Interactive slicers for Year, Region, Category
- KPIs for Total Sales, Profit, and Orders
- Visualizations: Bar Charts, Line Graphs, Maps, and Pie Charts
